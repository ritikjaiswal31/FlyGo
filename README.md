## FlyGo ✈️

---

### Airline Booking and Operations Platform

---

### Project Overview

FlyGo is a full-stack airline reservation and management system that enables users to search flights, create bookings, manage passenger details, and track reservations. The application is built using **Spring Boot** on the backend, **React** on the frontend, and **MySQL** for relational data persistence. It also provides role-based functionality for customers and administrators, including flight, airport, and booking management with booking confirmation emails.

---

### Real-World Use Case

* FlyGo provides a centralized platform for customers to search available flights, create reservations with passenger details, track their bookings, and receive booking confirmation emails.

* Administrators can manage airports, flights, and customer bookings through a dedicated Admin Dashboard, providing centralized control over airline booking operations.

* Flight operations can be tracked using statuses such as **SCHEDULED, DELAYED, CANCELLED, DEPARTED, and ARRIVED**, while administrators can also update booking statuses.

---

### Key Features

* Flight search and reservation management
* Passenger details and booking history management
* Role-based access for **ADMIN, CUSTOMER, and PILOT**
* Admin Dashboard for managing flights, airports, and bookings
* Flight and booking status management
* Booking confirmation email functionality
* RESTful communication between **React** and **Spring Boot**
* Relational data persistence using **MySQL**
